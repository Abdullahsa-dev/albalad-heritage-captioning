# Al-Balad: Domain-Adapted Vision-Language Captioning for Historic Jeddah Heritage Houses

Fine-tuning a compact vision-language model so it can recognize and describe individual heritage houses in Historic Jeddah (Al-Balad), a UNESCO World Heritage site.

Research training project at the Center of Research Excellence for Smart Environment (CRES), King Abdulaziz University.

![Qualitative examples](results/figures/qualitative_examples.png)

## The problem

General-purpose vision-language models do not know Al-Balad. Out of the box, the base model described Bayt Farwan as a building in Muscat, Oman, and Bayt Nassif as a mosque in Damascus. It never named a single house correctly.

## The approach

1. **Data preparation.** Building metadata (style, materials, floors, location) is cleaned and matched with human survey descriptions and day/night photographs of each house.
2. **Caption generation.** [Qwen3-VL-2B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct) writes a description for every image, grounded in that building's metadata and survey context.
3. **Fine-tuning.** The same 2B model is fine-tuned on the image and caption pairs with QLoRA (4-bit NF4 quantization plus LoRA adapters), which fits on a single Colab GPU.
4. **Evaluation.** Base and fine-tuned models are compared on a held-out test set under identical, deterministic generation settings.

## Results

Held-out test set: 287 images (197 day, 90 night) across 39 buildings.

| Metric | Base | Fine-tuned |
|---|---|---|
| Corpus BLEU-4 | 0.034 | 0.262 |
| ROUGE-L F1 | 0.236 | 0.421 |
| METEOR | 0.228 | 0.448 |
| BERTScore F1 | 0.194 | 0.459 |
| Building identification accuracy | 0.00% | 55.05% |
| Macro building accuracy | 0.00% | 33.84% |

- Every improvement is statistically significant (paired bootstrap 95% confidence intervals, Wilcoxon signed-rank and exact McNemar tests).
- Accuracy is almost the same in daylight (54.82%) and at night (55.56%).

![Caption metrics](results/figures/figure_overall_caption_metrics.png)

## Limitations

- The reference captions are synthetic (generated by Qwen3-VL from metadata and survey context), so the text metrics measure agreement with those references. They are not independent proof of historical accuracy.
- Accuracy is uneven across buildings. Houses with few training images are often misidentified.
- Human evaluation was not completed. CIDEr could not be computed during the evaluation run and is not reported.

## Repository contents

| Path | What it is |
|---|---|
| `notebooks/01_building_metadata_cleaning_eda.ipynb` | Cleans and explores the building metadata |
| `notebooks/02_albalad_dataset_q2.ipynb` | Early pilot of the captioning pipeline on two houses (Nassif and Noorwali) |
| `notebooks/03_caption_generation_qwen3vl_2b.ipynb` | Generates the caption dataset with Qwen3-VL-2B |
| `notebooks/03b_caption_generation_qwen3vl_4b.ipynb` | Same pipeline with the 4B model, for comparison |
| `notebooks/06_evaluate_albalad_v1.ipynb` | Base vs. fine-tuned evaluation on the test set |
| `notebooks/07_external_image_testing.ipynb` | Tests the fine-tuned model on photos outside the dataset |
| `notebooks/08_single_external_image_human_evaluation.ipynb` | Caption one image and record a human rating |
| `results/metrics/` | Metric tables, confidence intervals and significance tests (CSV) |
| `results/figures/` | Evaluation charts and qualitative examples |
| `results/run_status.json` | Summary of the fine-tuning run (3 epochs, 867 steps) |

Notebook outputs were cleared before publishing. The image dataset, survey responses and the trained adapter are not included in this repository.

## Running the notebooks

The notebooks were written for Google Colab with a GPU and read their data from Google Drive. Update the Drive paths in each configuration cell to match your own folders. Main packages are listed in `requirements.txt`.
